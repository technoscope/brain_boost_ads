# Brain Boost - Ads & Privacy

This repository hosts the public-facing files required for the Brain Boost Android game
published on the Google Play Store.

## Files

| File | URL | Purpose |
|---|---|---|
| `app-ads.txt` | `/app-ads.txt` | AdMob publisher verification |
| `privacy-policy.html` | `/privacy-policy.html` | Privacy policy (required by Google Play) |

## Setup

GitHub Pages is enabled on the `main` branch root.

**Live URLs:**
- https://technoscope.github.io/brain_boost_ads/app-ads.txt
